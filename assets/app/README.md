# PixMe icons

| File | Use |
|---|---|
| `PixMe.ico` | Windows executable icon (16, 24, 32, 48, 64, 128, 256 px; small sizes redrawn pixel by pixel) |
| `PixMe.icns` | macOS app bundle icon (16 to 1024 px, with baked-in shadow) |
| `pixme-window-256.png` | Window icon (RGBA PNG, Windows variant) |
| `pixme-1024.png` | macOS master, for docs and stores |
| `menubar-template.png`, `menubar-template@2x.png` | macOS menu bar icon: black on transparent, to be loaded as a template image |
| `PixMe.svg` | Vector source (macOS layout, without shadow) |

Original artwork created for PixMe. No third-party assets.
